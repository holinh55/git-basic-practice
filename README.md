# Git Basic Practice

Repository tổng hợp bài thực hành Git.

## Bài 1 - 5

Các bài 1 đến 5 được thực hiện trực tiếp trong repository này.

Nội dung thực hành gồm:
- Khởi tạo Git repository và commit
- Staging Area
- Thực hành nhiều commit
- Checkout và Reset
- Kết nối GitHub Remote
- Clone, Pull và Push
